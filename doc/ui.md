# UI режим

## Запуск

```bash
go run . ui
```

Флаги:

- `--category` - начальная категория (`last`, `ongoing`, `announce`, `finished`, `films`, `favorite`, `watching`, `planned`, `watched`, `delayed`, `abandoned`)
- `--page` - стартовая страница

## Разделы

- Главная: категории ленты
- Закладки: `favorite`, `watching`, `planned`, `watched`, `delayed`, `abandoned`

Переключение:

- `b` - в закладки
- `g` - на главную

## Горячие клавиши

### Сетка карточек

- `h/j/k/l` или стрелки - навигация
- `Enter` - открыть детали
- `Tab` / `Shift+Tab` / `[` / `]` - сменить категорию
- `n` / `p` - следующая/предыдущая страница
- `r` - перезагрузить страницу
- `w` - запустить просмотр
- `m` - переключить плеер (`auto` -> `mpv` -> `vlc` -> `ffplay`)
- `f` - избранное
- `0..5` - статус списка
- `i` - вход
- `u` - регистрация
- `o` - выход из аккаунта
- `q` - выход из UI

### Экран деталей

- `esc` - назад
- `j/k` или `↑/↓` - скролл
- `PgUp` / `PgDn` / `Home` - быстрый скролл
- `w` - просмотр
- `m` - переключить плеер для просмотра
- `f`, `0..5`, `i`, `u`, `o` - те же действия, что и в сетке

### Форма авторизации

- `Tab` / `Shift+Tab` - переключение полей
- `Enter` - отправка
- `Esc` - закрыть форму

## Примечания

UI использует API в реальном времени и поддерживает:

- просмотр карточек тайтлов;
- открытие полной информации;
- быстрый переход к просмотру в локальном плеере;
- базовые действия с избранным и списками.
