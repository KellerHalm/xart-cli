# Xart-CLI - консольный клиент Anixart/Xart на Go

CLI повторяет основные возможности сайта [xart-rose.vercel.app](https://xart-rose.vercel.app) через API [https://openanix.ru/anixart-api-docs/](https://openanix.ru/anixart-api-docs/).

## Возможности

- авторизация и работа с токеном;
- главная лента и категории;
- discovery-раздел;
- поиск релизов, профилей, коллекций и списков;
- релизы, эпизоды, источники плеера, комментарии и оценки;
- закладки, избранное и история;
- коллекции и комментарии коллекций;
- профиль, друзья, блокировки и настройки;
- интерактивный терминальный UI;
- быстрый запуск видео в локальном плеере через `watch`.

## Установка и запуск

```bash
go mod tidy
go run . --help
```

Сборка бинарника:

```bash
go build -o xart.exe .
```

## Быстрый старт

```bash
# Вход и сохранение токена в ~/.xart-cli/config.json
go run . auth login --login your_login --password your_password

# Главная категория "последнее"
go run . home list last --page 0

# Поиск релизов
go run . search releases --query "наруто" --by name --page 0

# Информация о релизе
go run . release info --id 18174

# Смотреть видео из терминала
go run . watch --id 17443
```

## UI режим

```bash
go run . ui
```

Для просмотра видео нужен установленный плеер: `mpv`, `vlc` или `ffplay`.

Основные клавиши UI:

- `h/j/k/l` или стрелки: перемещение по карточкам;
- `Enter`: открыть детали тайтла;
- `w`: запуск просмотра (перед запуском можно выбрать озвучку);
- `m`: переключить предпочтительный плеер (`auto` -> `mpv` -> `vlc` -> `ffplay`);
- `f`: добавить/убрать из избранного;
- `0..5`: установить статус списка;
- `b`: открыть раздел закладок;
- `g`: вернуться в главную;
- `Tab` или `[` `]`: сменить категорию;
- `n` / `p`: следующая / предыдущая страница;
- `r`: перезагрузить текущую страницу;
- `esc`: выйти из деталей/отменить выбор озвучки;
- в деталях: `j/k` или `↑/↓` для скролла;
- `i`: открыть форму входа;
- `u`: открыть форму регистрации;
- `o`: выйти из аккаунта;
- `q`: выход из UI.

Категории закладок в UI:

- `favorite`, `watching`, `planned`, `watched`, `delayed`, `abandoned`.

## Команда watch

Команда `watch` подбирает озвучку, источник и эпизод, затем запускает внешний плеер.

```bash
go run . watch --id 17443
```

Полезные опции:

- `--voiceover-id` - выбрать конкретную озвучку;
- `--choose-voiceover` - выбрать озвучку интерактивно перед запуском;
- `--source-id` - выбрать конкретный источник;
- `--episode` - выбрать позицию эпизода;
- `--player` - указать плеер или путь до исполняемого файла;
- `--choose-player` - перед запуском показать интерактивный выбор плеера;
- `--player-arg` - передать дополнительные аргументы плееру;
- `--print-url` - вывести URL эпизода без запуска плеера;
- `--no-progress` - не отмечать прогресс просмотра в профиле.

## Конфиг

Файл конфигурации: `~/.xart-cli/config.json`.

Поля:

- `api_base_url` (по умолчанию `https://openanix.ru/anixart-api-docs/`);
- `user_agent`;
- `token`;
- `user_id`.
